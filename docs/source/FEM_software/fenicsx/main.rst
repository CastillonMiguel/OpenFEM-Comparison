FEniCSx / PhaseFieldX
===================== 

`FEniCSx <https://fenicsproject.org/>`_ (:footcite:t:`code_BarattaEtal2023` :footcite:t:`code_basix` :footcite:t:`code_ufl`) is an open-source computing platform for solving partial differential equations using the finite element method. Its components include DOLFINx, which provides the problem-solving environment; UFL (Unified Form Language), which allows users to express variational formulations; and Basix, which provides finite element basis functions and related operations.

`PhaseFieldX <https://github.com/CastillonMiguel/phasefieldx>`_ (:footcite:t:`code_phasefieldx`) is an open-source framework built on FEniCSx for advanced phase-field simulations. It provides implementations of phase-field models and numerical methods for applications such as fracture and fatigue analysis.

Installation

For installation instructions, dependencies, and environment configuration, refer to the official PhaseFieldX repository:

* `PhaseFieldX repository and installation instructions <https://github.com/CastillonMiguel/phasefieldx>`_

Follow the instructions provided in the repository to install PhaseFieldX and its required dependencies, including a compatible version of FEniCSx.

For further information about the underlying finite element framework, consult the official `FEniCSx documentation <https://docs.fenicsproject.org/>`_.
